# Aura iOS

Private source snapshot of the existing native Swift app and Supabase backend.

Open `Aura iOS/Aura iOS.xcodeproj` in Xcode. The committed `Package.resolved` pins Swift dependencies. Start with `AGENTS.md` and its task-specific documentation routes.

## Snapshot provenance

Captured from the current working files of the original Aura checkout on September 14, 2026, including uncommitted launch fixes and the flat app icon. This repository starts fresh history; the original local repository and its history remain intact. Generated builds, signing credentials, local agent state, scratch media and audit outputs are excluded. Build assets and backend sources are preserved.

## Release status

This source includes the local version 1.0 build 2 candidate. Build 1 was previously uploaded and validated by Apple; that evidence does not validate this newer build. Build 2 remains subject to distribution validation and owner device testing. Historical checklists under `docs/` record earlier states and are not current completion certificates.

Do not submit the app or subscriptions for Apple review without the owner's instruction. Minor UI/UX adjustments, physical-device and native StoreKit testing, App Store screenshots, subscription-review screenshots, and subscription staging/submission remain owner tasks.

Rork's documented GitHub import reconstructs a new app rather than adopting this Xcode project. A review of that reconstruction would not validate this source or its release archive.
